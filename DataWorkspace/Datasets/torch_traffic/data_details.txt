This folder will contain the code for all the traffic datasets that are provided by Torch Spatiotemporal, because they function similarly and are all sourced from the same place.
These are PeMS, METR-LA, PeMS Bay, LargeST

Since LargeST functions somewhat differently I'm putting it in its own class.
PeMS (03, 04, 07, 08), METR-LA, and PeMS Bay function the same so they are in one torch_traffic_dataset class
Note that all the datasets have a pairwise distance adjacency matrix between their nodes.

Info for each dataset:
METR-LA:
    -Sampling Rate: 5 minutes
    -Data collection period: 4 months, 34272 data points
    -Missing values: 8.11%
    -207 Sensors, that give us the car speeds at that sensor.
    -We are given the sensor's geographical coordinates

PeMS Bay:
    -Sampling Rate: 5 minutes
    -Data collection period: 6 months, 52128 data points
    -Missing values: 0.02%
    -325 Sensors, that give us the car speeds at that sensor.
    -We are given the sensor's geographical coordinates
